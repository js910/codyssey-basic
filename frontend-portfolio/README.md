# Frontend Portfolio

HTML, CSS, JavaScript를 사용하여 제작한 반응형 개인 포트폴리오 웹사이트입니다.

## 📌 프로젝트 소개

웹 개발의 기초인 HTML, CSS, JavaScript를 활용하여 포트폴리오 페이지를 구현했습니다.

* 반응형 웹 디자인
* 다크 모드
* 모바일 햄버거 메뉴
* 스크롤 애니메이션
* Contact Form 유효성 검사
* GitHub API를 이용한 프로젝트 동적 렌더링

## 🛠 기술 스택

* HTML5
* CSS3
* JavaScript
* GitHub REST API
* Git / GitHub

## 📁 프로젝트 구조

```text
frontend-portfolio/

│   └── style.css

```

## ✨ 주요 기능

### 반응형 웹

모바일, 태블릿, 데스크톱 환경에 맞게 레이아웃이 변경

### 다크 모드

다크 모드 전환 기능과 `localStorage`를 이용한 테마 설정 저장 기능

### GitHub API

GitHub API를 통해 실제 Repository 정보를 가져와 Projects 영역에 동적으로 표시

API 요청 상태에 따라 다음 UI를 제공

* 로딩
* 성공
* 에러 및 재시도
* 프로젝트 없음

Fork Repository는 제외하고 본인 프로젝트만 표시

### Contact Form

이름, 이메일, 메시지의 필수 입력 및 이메일 형식을 검사하고 입력 오류를 화면에 표시

### JavaScript 인터랙션

* 햄버거 메뉴
* 부드러운 스크롤
* Scroll To Top
* 스크롤에 따른 Header 변경
* Intersection Observer를 이용한 스크롤 애니메이션
